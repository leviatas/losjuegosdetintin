# Los juegos de Tintin

Juegos web para chicos, con la misma base que *Los juegos de Amelia*
(Express dockerizado, PWA, hub de juegos, monedas, registro de visitas).
Por ahora trae un solo juego: **Sky Run** ☁️, un runner 3D (Three.js) entre las
nubes con personajes elegibles y tres dificultades.

## Correr

```bash
docker compose up -d --build   # http://localhost:5174
# o, sin Docker:
npm install && npm start       # http://localhost:3000
```
